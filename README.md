**Night Shift: The Quiet Vault** — a complete top-down stealth game that plays offline in a desktop browser. You are the thief the museum never sees: three wings, three sets of patrols, one quiet exit each. Guards walk real patrol routes with vision cones clipped by walls and crates; getting spotted fills their suspicion ring, and a full ring raises the alarm and a chase. Sneak with Shift, hide in the dark shadow floor, slip behind crates, grab every data shard to unlock the green exit, and get out unseen. A ghost run — never spotted in a wing — earns a bonus. Synthesized footsteps pan left and right so you can hear where a patrol is, and the whole game is static files with no network request.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. WASD / arrows to move, Shift to sneak, click to walk there, P pauses, M mutes.
